# 尼罗河神话地图 · Nile Myth Atlas

一份沿尼罗河从北到南展开的埃及神话与旅行互动图录。页面把神庙、神话故事和旅行路线放在同一张地图上，帮助你在出发前了解地点，也可以作为旅途中的轻量参考。

## 在线访问

启用 GitHub Pages 后，可通过以下地址访问：

<https://QUQU12138223.github.io/nile-myth-atlas/>

如果页面暂时无法打开，请在仓库的 **Settings → Pages** 中，将 **Build and deployment** 的来源设为 **Deploy from a branch**，分支选择 **main**、目录选择 **/(root)** 并保存。等待 GitHub Pages 完成部署后再访问上面的链接。

## 内容与功能

- **尼罗河神庙地图**：按北到南的示意位置浏览 15 个神庙与遗址，并可从地图跳转到相应条目。
- **神庙图录**：按主题筛选地点，查看主神、年代、位置、参观重点、旅行提示及平面示意图。
- **六段神话**：阅读创世、奥西里斯、荷鲁斯、伊西斯、太阳船与尼罗河泛滥等主题故事，并跳转到相关地点。
- **十天行程**：参考从开罗到阿布辛贝的北上南下路线，并可填写出发日查看日期。
- **现场词表**：搜索神庙构造、神祇和旅行用语的中英阿文词条。
- **旅行进度**：标记已到访地点；进度保存在当前浏览器的本地存储中。
- **响应式与主题**：适配手机和桌面屏幕，并支持深色外观。

## 本地预览

这是一个无需构建工具的静态 HTML 页面。下载或克隆仓库后，直接用浏览器打开 `index.html` 即可；入口页会转到主页面 `nile-myth-atlas.html`。

## 文件

- `index.html`：网站入口，跳转到主页面。
- `nile-myth-atlas.html`：交互式图录的主体页面。

## 说明

地图为神庙分布示意，并非测绘地图。开放时间、票价、交通与旅行安排请以当地最新信息及现场公告为准。内容用于文化与旅行参考，不构成专业考古资料或旅行安全建议。
